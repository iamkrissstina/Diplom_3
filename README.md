# Автотесты для UI 

> Автотесты для веб-приложения Stellar Burgers.
> 
> Тесты покрывают сценарии регистрации, авторизации и работы с разделом «Конструктор» в браузерах Google Chrome и Яндекс Браузер. Отчётность — через Allure.
> 
> Стек: Java 11, JUnit 4.13.2, Selenium 4.38.0, Allure 2.15.0, RestAssured 5.5.6, WebDriverManager 6.3.2, JavaFaker 1.0.2, Lombok 1.18.42, AspectJ 1.9.7.

---

## Используемые подходы и инструменты

- **Page Object**: все элементы и действия инкапсулированы в отдельных классах страниц (`MainPage`, `LoginPage`, `RegisterPage`, `RecoverPasswordPage`).
- **Браузеры**: Google Chrome, Яндекс Браузер (поддержка через Selenium).
- **Отчётность**: Allure (с аннотациями `@DisplayName` и `@Description` для понятных названий и описаний тестов).
- **Управление данными**: тестовые пользователи генерируются перед тестом и удаляются после него.
- **Lombok**: для сокращения шаблонного кода, что делает код тестов чище и компактнее.
- **JavaFaker**: позволяет создавать уникальные данные для каждого прогона тестов и избегать жёстко заданных значений.
---

## Команды 

```bash
# Запуск тестов и генерация Allure-отчёта
mvn clean test allure:report

# Просмотр отчёта в локальном сервере
allure serve target/allure-results
